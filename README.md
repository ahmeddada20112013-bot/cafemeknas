# مقهى مكناس — تطبيق الطلبات والأثمنة (مقهى + صالة ألعاب)

تطبيق ويب بسيط يعمل مباشرة في المتصفح، بدون خادم وبدون إنترنت.

## التشغيل
افتح الملف `index.html` في المتصفح (Chrome / Edge / Firefox)، على الحاسوب أو اللوحة اللوحية.

## المميزات
- **قسمان منفصلان:** تبويب «☕ المقهى» لطاولات المقهى، وتبويب «🎮 صالة الألعاب» لمحطات الألعاب (بلايستيشن، بلياردو، بيبي فوت، تنس الطاولة...)، لكل قسم ملخصه الخاص (المشغول، الطلبات المفتوحة، مبيعات اليوم).
- **تسجيل الطلبات:** الضغط على طاولة يفتح قائمة المنتجات حسب الأصناف، مع تعديل الكميات.
- **احتساب اللعب:**
  - **بالساعة:** مؤقت (بدء / إيقاف مؤقت / استئناف / +15 دقيقة)، مع تقريب الوقت (مثلاً لكل 15 دقيقة) وحد أدنى (مثلاً 30 دقيقة) قابلين للتعديل.
  - **بالجولة:** عدّاد للجولات/المباريات.
- **الفاتورة:** مجموع المنتجات + ثمن اللعب − التخفيض، طريقة الدفع (نقداً / بطاقة)، طباعة فاتورة (مناسبة لطابعات 80مم)، وطباعة فاتورة مؤقتة.
- **نقل الطلب** من طاولة إلى أخرى (عند النقل من محطة ألعاب إلى طاولة يُضاف ثمن اللعب كبند).
- **قائمة المنتجات:** إضافة / تعديل / حذف المنتجات والأصناف والأثمنة.
- **التقارير:** مداخيل اليوم أو أي فترة مع إمكانية اختيار القسم (الكل / المقهى / صالة الألعاب)، مداخيل المقهى مقابل الألعاب، نقداً/بطاقة، الأكثر مبيعاً، مداخيل كل محطة ألعاب، سجل الفواتير مع إعادة الطباعة، وتصدير CSV (Excel).
- **الإعدادات:** اسم المقهى، العملة، قواعد احتساب الوقت، إدارة الطاولات والمحطات، نسخة احتياطية (تصدير/استيراد JSON).

## ملاحظة مهمة
البيانات تُحفظ في متصفح الجهاز (localStorage). استعمل نفس المتصفح دائماً، وصدّر نسخة احتياطية بانتظام من صفحة الإعدادات.
